↓

核心原则：
1. Hermes 理解意图，但不持有 HA Write / Approve / Execute 工具。
2.“把 Max AC 改成 1 kW” “切换 BACKUP” “关闭客厅插座”等语音，都可以被理解。
3. 任何可能改变真实能源设备状态的语音，都先转换成 显式 Proposal / Action Set。
4. 用户必须看到“将改变哪些设备、当前值 → 目标值、预期家庭影响” 。
5. V1 默认使用 物理触摸长按确认完成最终 Approval。
6. 语音本身不是身份认证，不允许环境中的一句话直接触发高风险设备写入。
7.“执行刚才方案”可以被理解为 Approval Intent，但仍需终端展示当前 Proposal 并要求确认。
8. 最终成功不是“命令发出” ，而是Device Readback + Smart Meter Household Outcome Verification。
1. 产品定义
1.1 一句话定义
GuangHeng Energy Companion 是光衡 Autonomous Energy Agent 的实体化入口：平时以低打扰方式显示
家庭能源状态，需要用户介入时主动提醒；用户可以拿起设备查看解释，也可以点击语音按钮直接询问家庭能
源、让 Hermes 理解控制意图、生成策略或跨设备 Action Set，并在用户确认和 Safety 后执行，最终由 Smart
Meter 验证家庭能源是否真的发生预期变化。
1.2 它不是什么
Energy Companion 不是：
・ 缩小版 Flutter App
・ Home Assistant 遥控器
・ 直接持有 HA Token 的控制终端
・ 独立能源 Optimizer
・ 独立审批真相源
・ 本地运行 Hermes 的设备
・ 一句语音即可绕过 Safety 的智能音箱
・ 家庭储能设备本身
1.3 它是什么
它是：
Ambient Energy Display
+
Voice Agent Interface
+
Lift‑to‑Explain
+
Magnetic Context
+
Proposal Companion
+
Quick Approval Terminal
+
Execution / Verification Display

P0 阶段建议先只接 4 根线。 TMAG5273 的 INT 中断脚先不接，通过 I2C 定时采样完成磁吸 / 非磁吸识别；这样

I2C 总线说明
Waveshare 官方资料明确说明本板引出了 1 路 I2C，可供外接设备使用。当前官方 BSP 还提供 I2C 扫描示例，建
议先运行 00_board_check / 08_i2c_tools，以你手中板卡 revision 的实际 BSP 输出为准确认 SDA/SCL，而不是仅
凭网络图片焊接。
对于部分 V1 资料和社区硬件映射，板载共享 I2C 常见为：
SCL = GPIO14
SDA = GPIO15
但 最终生产接线必须以你的板背 Revision、官方 BSP board‑check 输出或原理图为准 。V1 与 V2 的显示 / 触摸
硬件已经不同，因此不要把旧版 pin map 当成所有版本的永久事实。
63.3 TMAG5273 I2C 地址
如果你购买的是 TMAG5273A2，TI 数据手册给出的默认 7‑bit I2C 地址为：

A2 对应高量程版本。若模块完整型号不是 A2，则先读取模块 / 芯片丝印确认；不同版本可能使用不同默认地址。
