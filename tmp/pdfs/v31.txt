        1. 产品定义与目标                                                                
                                                                                  
                                                                                  
                                                                                  
        光衡是一套运行在   Home Assistant 生态上的家庭能源智能调度系统。它持续理解光伏、储能、负载、电价和天气，             
        在未来条件变化时主动判断是否值得重规划，并在用户批准后安全改变设备参数。                                      
                                                                                  
        核心问题                                                                      
                                                                                  
                                                                                  
         不是“现在电池还有多少”，而是“为了接下来会发生的变化，现在是否值得调整计划？不调整会怎样                            
         ？调整后能获得什么可验证价值？”                                                         
                                                                                  
                                                                                  
        产品目标                                                                      
                                                                                  
         • 把能源数据从展示升级为预测、决策、执行、解释和验证。                                             
         • 在不把底层功率交给  LLM 自由生成的前提下，体现  Agent 的主动性。                                
                                                                                  
         • 让用户清楚看到发生了什么、为什么现在行动、会改变什么、收益和风险是什么。                                   
                                                                                  
         • 通过真实读回或同 Schema Replay 证明执行闭环，而不是只展示 UI。                               
                                                                                  
        非目标

        9. Energy    Optimizer     数学定义                                           
                                                                                  
                                                                                  
                                                                                  
        时间域为未来  24 小时，默认 30 分钟时间片，N=48，Δt=0.5h。所有输入由 ContextSnapshot 锁定，Optimizer 
        在相同输入与版本下必须返回相同输出。                                                        
                                                                                  
        决策变量                                                                      
                                                                                  
        P_charge[t] ≥ 0；P_discharge[t] ≥ 0；P_import[t] ≥ 0；P_export[t] ≥ 0；SOC[t] ∈ [0,1]
                                                                                  
        SOC  状态转移                                                                 
                                                                                  
        SOC[t+1] = SOC[t] + (η_charge × P_charge[t] × Δt / C) - (P_discharge[t] × Δt / (η_discharge × C))
                                                                                  
        功率平衡                                                                      
                                                                                  
        PV[t] + P_import[t] + P_discharge[t] = Load[t] + P_charge[t] + P_export[t]

        目标函数                                                                      
                                                                                  
        min Σt { buy_price[t]×P_import[t]×Δt - sell_price[t]×P_export[t]×Δt + λ_cycle×(P_charge[t]+P_discharge[t])×Δt +
        λ_peak×PeakImportPenalty[t] + λ_reserve×ReserveViolation[t] + λ_switch×ModeChange[t] }
        硬约束                                                                       
                                                                                  
         • SOC_min ≤ SOC[t] ≤ SOC_max；在指定窗口 SOC[t] ≥ reserve_soc[t]。              
                                                                                  
         • 0 ≤ P_charge[t] ≤ device_max_charge；0 ≤ P_discharge[t] ≤ device_max_discharge。
                                                                                  
         • 同一时间片不得同时充放电；MVP  可通过二元变量或互斥后处理实现。                                     
         • 所有设定值按设备 step 取整；取整后再次校验 SOC 和功率平衡。                                    
                                                                                  
         • 无可行解时返回 infeasible + reasons，不得构造虚假 Proposal。                          
                                                                                  
        策略权重                                                                      
                                                                                  
             模式               主要目标                        权重原则                    
                                                                                  
         SAVE         最低电费                   成本和峰时购电权重最高，仍遵守用户  Reserve           
         AUTO         成本、自用率、备电平衡            默认；中等循环惩罚，平衡多目标                      
                                                                                  
         BACKUP       停电韧性                   Reserve 违约为极高惩罚，限制套利放电               
                                                                                  
        10.  Baseline    与价值计算                                                    
                                                                                  
                                                                                  
                                                                                  
        Baseline                                                                  
        不是另一组随意数据，而是在完全相同场景下“不采用本次重规划”的反事实结果。所有对比必须使用同一初始                         
                                                                                  
        SOC、设备能力、天气、负载、电价、时间范围和预测版本。                                              
                                                                                  
                 指标                                定义                             
         Energy Cost         Σ(购入电量×购入价 − 送出电量×售出价)                               
                                                                                  
         Smart Savings       Baseline Cost − Optimized Cost；小于 0 时必须如实显示          
                                                                                  
         Solar Self-use      家庭直接使用 PV + PV 充入电池后自用 / PV 总发电                      
         Peak Import         高峰电价时间段的电网购电量                                        
                                                                                  
         Battery Throughput  Σ(充电量 + 放电量) / 2，用于说明循环代价                            
                                                                                  
         Backup Hours        可用电池能量 / 关键负载预测功率；展示假设和范围                            
         Forecast Error      MAPE / MAE；仅在实际数据到达后计算                               
                                                                                  
        展示规则                                                                      
                                                                                  
         • 预测价值使用“预计”并展示区间；实际完成后才能显示“实际节省”。                                       
                                                                                  
         • 预计节省区间通过 PV / Load 的低、中、高三种情景计算，不伪造统计置信度。                              
         • 若优化方案增加成本以换取备电，主文案显示“增加约      ¥X，获得约 Y 小时备电”，不能仍标为节省。                  
                                                                                  
         • Baseline 和 Optimized 必须记录 algorithm_version、input_hash 和 calculated_at。
